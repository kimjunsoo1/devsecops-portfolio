# 4주차 증적 — WAF 차단 기록
#
# 수집: 2026-11-03T04:45:43Z
# 방법: 본인 사이트에 경로탐색·XSS·Log4Shell 요청을 보낸 뒤 WAF 샘플 조회
#
# 주의 1: 소스 IP 는 일부러 포함하지 않음
# 주의 2: WAF 샘플 기록은 3시간만 보관된다. 공격 직후에 수집해야 한다.
#         이것이 CKV2_AWS_31(WAF 전체 로깅) 유예의 한계이기도 하다 -
#         샘플은 일회성 검증에 충분하지만 사후 조사에는 부족하다.
#
# 참고: 클라이언트에는 403 이 아니라 404 가 보인다. CloudFront 의
#       custom_error_response 가 WAF 차단의 403 까지 덮기 때문이다.
#       아래 기록이 실제 차단 여부의 유일한 근거다.
